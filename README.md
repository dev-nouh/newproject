# Special Design 

Special Design is an interactive front-end project built mainly to practice and demonstrate JavaScript concepts through a real-world website.

##  About The Project

This project focuses heavily on JavaScript functionality and interactive UI features rather than responsive design.

I worked with the **DOM and BOM** to create different dynamic features and make the website interactive.

##  Features

*  Change the website's main color
*  Random background images
*  Save settings using Local Storage
*  Settings panel with toggle functionality
*  Animated skills progress bars on scroll
*  Interactive image gallery with popup
*  Navigation bullets
*  Smooth scrolling between sections
*  Reset all saved settings
*  Random background using `setInterval`
*  DOM manipulation and event handling
*  BOM features such as `window`, `localStorage`, and `location`

##  Technologies Used

* HTML5
* CSS3
* JavaScript (ES6+)
* Bootstrap
* Font Awesome
* DOM
* BOM
* Local Storage

##  Responsiveness

**Note:** This project is **not fully responsive**.

The main goal of this project was to practice JavaScript, DOM manipulation, BOM, Events, Local Storage, and building interactive website features.

##  What I Learned

Through this project, I practiced how to:

* Manipulate HTML elements using JavaScript
* Handle user events
* Store and retrieve data using Local Storage
* Create dynamic elements using JavaScript
* Control CSS properties using JavaScript
* Work with browser APIs
* Build interactive UI components
* Combine multiple JavaScript concepts together in one project
